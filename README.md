# Скрипты AWTRIX NG для Ulanzi TC001

Набор компактных Berry-приложений для часов Ulanzi TC001 с прошивкой AWTRIX NG.

Идея и постановка задач: **Valart**.

## Состав

- `apps/social_counter.ax` — счётчик подписчиков Likee с увеличенным логотипом 8×8 и градиентным числом;
- `apps/weather_open_meteo.ax` — текущая температура, погодная иконка, почасовой цветовой прогноз и стрелка температурного тренда;
- `apps/pollen_open_meteo.ax` — доминирующий аллерген; приложение автоматически скрывается при нулевой концентрации;
- `apps/night_clock.ax` — ночные часы с отдельной яркостью и цветом; дневные параметры берутся из настроек устройства;
- `icons/weather` — погодные GIF-иконки 8×8.

Скрипты экономят память ESP32, не выполняют сетевые запросы во время отрисовки, ограничивают размер
принимаемых ответов и сохраняют последнее корректное значение.

## Установка

1. Установите [AWTRIX NG](https://blueforcer.github.io/awtrix-ng/) и подключите часы к Wi-Fi.
2. В Web UI часов откройте раздел **Scripts**.
3. Создайте приложения с точными именами и вставьте соответствующий исходный код:
   - `social_counter` — `apps/social_counter.ax`;
   - `weather_open_meteo` — `apps/weather_open_meteo.ax`;
   - `pollen_open_meteo` — `apps/pollen_open_meteo.ax`;
   - `NightClock` — `apps/night_clock.ax`.
4. Загрузите файлы из `icons/weather` в каталог `ICONS` на часах.
5. Откройте настройки каждого приложения и укажите необходимые параметры.

## Погода и пыльца

Оба приложения используют бесплатные API [Open-Meteo](https://open-meteo.com/) без ключа.
Координаты задаются десятичными градусами, например для Москвы:

- широта: `55.7558`;
- долгота: `37.6176`.

Погода обновляется по умолчанию раз в 30 минут. Пыльца обновляется раз в 3 часа и выводится только
тогда, когда концентрация хотя бы одного поддерживаемого аллергена выше нуля.

Параметр `weather_ip` используется как резервный IP Open-Meteo в модифицированной сборке AWTRIX NG.
На стандартной сборке запрос продолжит работать через обычное разрешение доменного имени.

## Likee

Укажите Likee ID в настройках приложения. Последнее корректное количество подписчиков сохраняется
и показывается после перезагрузки. Длинные значения автоматически сокращаются до `K`, `M` или `B`.

Likee не предоставляет стабильного открытого API для произвольного профиля. Скрипт использует
внутренний endpoint сервиса, поэтому в будущем он может потребовать обновления.

## Ночные часы

Настраиваются начало и окончание ночного периода, ночная яркость и цвет. Перед переходом в ночной
режим приложение запоминает текущие яркость и автояркость устройства, а утром восстанавливает их.
